# Games Portfolio Pro 🎮

A modern, beautiful gaming hub built with React, Tailwind CSS, and Framer Motion. Play amazing HTML5 games directly in your browser!

## Features ✨

- 🎮 **3 Amazing Games**: Flappy Bird, Snake Game, and Platformer Mini
- 🎨 **Beautiful UI**: Modern design with smooth animations
- 📱 **Responsive Design**: Works on all devices
- ⚡ **Fast Performance**: Optimized with Vite
- 🌐 **No Downloads**: Play directly in your browser

## Games Included 🕹️

1. **Flappy Bird** - Navigate through pipes in this classic reflex game
2. **Snake Game** - The classic retro serpent game - eat and grow!
3. **Platformer Mini** - Jump & Collect - gather coins and avoid enemies!

## Installation 🚀

```bash
# Clone the repository
git clone https://github.com/wkus2026/games-portfolio-pro.git
cd games-portfolio-pro

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack 💻

- **React 18** - UI library
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Vite** - Build tool
- **Three.js** - 3D effects (future)
